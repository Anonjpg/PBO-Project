# PBO-Project — Sistem Manajemen File

## Deskripsi
PBO-Project merupakan program sederhana untuk simulasi sistem manajemen file menggunakan bahasa pemrograman Python.

Proyek ini dibuat untuk menerapkan konsep Object-Oriented Programming (OOP), seperti class, object, inheritance, encapsulation, composition, serta exception handling.

## Fitur
- Membuat dan mengelola file.
- Membuat dan mengelola folder.
- Mengatur hak akses membaca dan menulis file.
- Menggunakan inheritance untuk berbagai jenis file.
- Melakukan validasi data.
- Mengimplementasikan custom exception.
- Menangani kesalahan menggunakan exception handling.

## Struktur Proyek

```text
PBO-Project/
│
├── main.py
├── test.py
├── pengguna.py
├── hak_akses.py
├── file.py
├── exceptions.py
├── Class Folder.py
└── README.md
```

## Teknologi
- Python 3
- Object-Oriented Programming (OOP)

## Cara Menjalankan

1. Clone repository:

   ```bash
   git clone https://github.com/Anonjpg/PBO-Project.git
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd PBO-Project
   ```

3. Jalankan program utama:

   ```bash
   python3 main.py
   ```
